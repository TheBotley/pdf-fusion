# PDF Fusion

### Combine your files. Create one PDF. Keep everything organized.

PDF Fusion is a free, modern and easy-to-use web application that allows you to combine multiple supported files into a single PDF document.

Whether you have PDF documents, images, text files, spreadsheets or presentations, PDF Fusion provides a simple way to bring your content together into one organized PDF.

No complicated software, no account registration and no unnecessary steps. Just upload your files, arrange them in the desired order and generate your final PDF.

---

## ✨ Features

### 📁 Multiple File Uploads
Import multiple files at once using the file selector or simply drag and drop them into the application.

### 🔄 File Organization
Easily manage your imported files before generating your PDF.

- Change the order of your files.
- Remove individual files.
- Clear your entire selection.
- Preview your imported file list.

### 📄 PDF Generation
Combine your supported files into one PDF document.

- Generate a single PDF from multiple sources.
- Choose a custom filename.
- Download the final document directly to your device.

### 🖼️ Multiple File Formats
PDF Fusion supports several common file formats, including:

- PDF documents
- JPG and JPEG images
- PNG images
- WEBP images
- GIF images
- BMP images
- SVG images
- TXT text files
- Markdown files
- CSV files
- JSON files
- XML files
- HTML files
- DOCX documents
- XLSX spreadsheets
- PPTX presentations

Actual support and conversion quality depend on the format and its contents. Office documents may be converted primarily into text, and complex formatting may not be preserved.

### 🔒 Privacy-Focused
Files are processed directly in your browser wherever supported by the application.

PDF Fusion does not require users to create an account or upload files to a dedicated PDF processing server.

External libraries and services may still be loaded when using the application.

### ⚡ Simple and Accessible
The application is designed to be straightforward, responsive and easy to use on desktop and mobile devices.

---

## 🚀 How to Use

1. Open PDF Fusion in your browser.
2. Select the files you want to combine.
3. Drag and drop files to organize their order.
4. Remove any files you do not need.
5. Enter a name for your final PDF.
6. Click the merge button.
7. Download your combined PDF.

That's it!

## 📦 Installation

You can run PDF Fusion locally without installing a backend server.

1. Clone this repository:

   `git clone https://github.com/YOUR-USERNAME/pdf-fusion.git`

2. Open the project folder.

3. Start a local HTTP server or use a development server such as VS Code Live Server.

4. Open the application in your browser.

---

## 🌍 Deployment

PDF Fusion can be deployed for free using GitHub Pages.

1. Open your repository settings.
2. Navigate to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch.
5. Select the `/ (root)` folder.
6. Click **Save**.

Your website will become available at:

`https://TheBotley.github.io/pdf-fusion/`

---

## ⚠️ Important Notes

PDF Fusion supports common file formats, but not every file extension can be converted into PDF automatically.

Some document formats require conversion and may lose complex layouts, embedded media, fonts or formatting.

Large files may require significant browser memory and processing time.

The maximum output size depends on the original files, browser capabilities and the selected conversion methods. PDF Fusion cannot guarantee compatibility with every AI platform or its upload limits.

Always check the resulting PDF before sharing it.
